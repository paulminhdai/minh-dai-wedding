🔍 Wedding Website API Diagnostic

What This Tool Does

This diagnostic tool tests all API endpoints to help troubleshoot issues with your deployed wedding website.

  • Tests server connectivity
  • Validates admin authentication
  • Checks database connection
  • Verifies RSVP functionality
Test 1: Health Check
Test 2: Admin Auth (Invalid Password)
Test 3: Admin Login (Valid Password)
Test 4: Guest Search
Run All Tests

🔧 Troubleshooting Tips

  • Test 1 fails: Server is not running or unreachable
  • Test 2 fails: Authentication endpoint not working
  • Test 3 fails: Check ADMIN_PASSWORD in Railway environment variables
  • Test 4 fails: Database connection issues (check SUPABASE_* variables)

Required Environment Variables in Railway:
• ADMIN_PASSWORD
• SUPABASE_URL
• SUPABASE_ANON_KEY
• SUPABASE_SERVICE_ROLE_KEY
• ENABLE_GUEST_VALIDATION (optional, defaults to true)
